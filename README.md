# Тасбих

Приложение для iPhone и Android (PWA): тасбих с анимированными чётками, зикры, салауаты, истигфар, азкары после намаза, утренние и вечерние азкары. Языки: русский и казахский. Регистрации нет, всё хранится на телефоне.

## Файлы

- `index.html` — страница приложения
- `css/app.css` — оформление и анимации
- `js/data.js` — тексты зикров (арабский, транскрипция, перевод) и надписи интерфейса
- `js/engine.js` — чётки, частицы фона (дождь, снег, лепестки), звук
- `js/app.js` — экраны, счёт, статистика, напоминания
- `sw.js`, `manifest.webmanifest` — работа офлайн и установка на экран «Домой»
- `img/bg/` — фоны, `img/icons/` — иконки, `img/raw/` — оригиналы картинок (на сайт выкладывать не нужно)

## Как посмотреть на ноутбуке

В VS Code поставить расширение **Live Server**, затем правый клик по `index.html` → «Open with Live Server».

## Как поставить на телефон

1. Выложить папку на сайт с https (например, GitHub Pages или Netlify).
2. iPhone: открыть ссылку в Safari → «Поделиться» → «На экран Домой».
3. Android: открыть в Chrome → меню → «Установить приложение».

После изменения файлов поменяйте `VERSION` в `sw.js`, чтобы телефон скачал новую версию.

## Перед тем как делиться

Тексты, транскрипцию и переводы нужно сверить с «Крепостью мусульманина» / «Мұсылманның қорғаны» и Мусхафом. Казахский перевод — черновик.
